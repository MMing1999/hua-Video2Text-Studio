          简介
          
                
          
                  Hua Video2Text Studio
                  是一个本地视频 / 音频转文字工作台：粘贴链接或选择本地文件，预览确认后转写，再在同一界面编辑、纠错与排版。
                
          
                
          
                  基于
                  lanbinleo/bili2text
                  （MIT）二次开发。上游提供下载、抽音频与语音识别等基础能力；本仓库增加了 Studio 前端、预览、任务队列、文件页、设置目录与 DeepSeek 排版等改造。
                
          
                
          怎么用：
          
                
            
                  
          1. 在「识别」粘贴链接或本地路径，先点预览确认。
            2. 
                  
          2. 选择引擎（默认 Whisper）后开始转写。
            3. 
                  
          3. 多条来源可先放进「队列」暂存，再批量转写。
            4. 
                  
          4. 完成后可编辑；需要时用 AI 纠错 / 排版（在「设置」配置）。
            5. 
                  
          5. 历史结果在「文件」，点击进入独立文稿页编辑；本地目录状态在「设置」。
            6. 
                
          
                
          
                  技术栈：yt-dlp · ffmpeg · Whisper 等 · DeepSeek Flash
          
                  仓库
                  MMing1999/hua-Video2Text-Studio
                  · License MIT
                
          
              
          

              
          
                
          适配平台
          
                
          下载依赖 yt-dlp。稳定度因平台风控而异；需登录的内容请在「设置」配置 Cookie。
          
                
          
                  
                    
          来源状态说明
          
                            
                  
                    
          
                      本地文件
                      已支持
                      常见音视频：mp4 / mkv / mov / mp3 / wav 等；也可上传
                    
          
                    
          
                      哔哩哔哩
                      已支持
                      BV 号、视频链接；多分 P；遇 412 可配 Cookie
                    
          
                    
          
                      AcFun（A 站）
                      已支持
                      acfun.cn 视频链接
                    
          
                    
          
                      YouTube
                      已支持
                      youtube.com / youtu.be；年龄限制等内容需 Cookie；海外网络可开代理
                    
          
                    
          
                      X / Instagram / Facebook
                      已支持
                      公开视频可试；私密 / 登录墙内容请配置浏览器 Cookie
                    
          
                    
          
                      抖音 / 小红书
                      实验性
                      风控变化快，可能偶发失败；请更新 yt-dlp 后单站验收
                    
          
                    
          
                      Telegram 等
                      未开放
                      建议先下载到本地再转写
                    
          
                            
                
          
              
          

              
          
                
          引擎说明
          
                
          转写引擎可在「识别 / 队列」页切换。默认推荐本机 Whisper；云端引擎需自行配置密钥与依赖。
          
                
          
                  
                    
          引擎类型说明
          
                            
                  
                    
          
                      Whisper
                      本地 · 免费
                      默认引擎。模型 tiny → large，越大越准也越慢；需安装 whisper 相关依赖
                    
          
                    
          
                      SenseVoice
                      本地
                      适合中文场景；需安装 sensevoice 依赖并准备模型
                    
          
                    
          
                      火山引擎
                      云端 API
                      走火山语音识别；需配置账号密钥，并安装 volcengine 依赖
                    
          
                    
          
                      MiMo
                      云端 API
                      OpenAI 兼容接口转写；需在配置中填写 API Key / Base URL
                    
          
                            
                
          
                
          
                  可选 AI 纠错 / 排版使用 DeepSeek（OpenAI 兼容），在「设置」中填写 Base URL、API Key 与模型名（如 deepseek-flash）。
                
          
              
          

              
          
                
          工作原理
          
                
          一次转写大致按下面流水线执行；「识别」页进度条对应这些阶段。
          
                
            
                  
          1. 准备：解析输入（BV / 链接 / 本地路径），创建任务并进入队列。
            2. 
                  
          2. 下载：在线来源用 yt-dlp 拉取音视频；本地文件则跳过此步。
            3. 
                  
          3. 提取：用 ffmpeg 从视频抽出音频轨，供识别引擎使用。
            4. 
                  
          4. 识别：调用所选引擎（Whisper / SenseVoice / 云端 API）生成原文稿。
            5. 
                  
          5. 写入：把文稿与元数据写入本地工作区，并可在 Studio 中继续编辑。
            6. 
                  
          6. 完成：可选再走 AI 纠错 / 排版；历史记录可在「文件」中回看。
            7. 
                
          
                
          
                  批量任务只是把多条来源依次（或排队）送进同一流水线；暂存队列保存在浏览器本地，提交后才进入服务端任务表。
